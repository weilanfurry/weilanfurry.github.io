产品概述

OVERVIEW // AI Agent 软件

WorkHolic 是牵引力工作室 Qomo 产品线下的 AI Agent 软件： 接收目标后自动拆解任务、调用工具并持续执行， 面向日常工作流与轻量开发场景，过程可查看、可随时人工接管。

核心目标

  • 用自然语言交代目标，由 Agent 自主完成多步任务。
  • 把任务拆解、工具调用与执行记录放在同一套流程中。
  • 降低 AI 任务的接入与编排门槛，并保留人工接管入口。

当前状态

STATUS // 开发阶段
  • 处于研发阶段，产品形态与核心流程设计进行中。
  • 尚未正式上线，仓库暂未公开。
  • 正式发布后将在 GitHub 组织下开放源码与文档。

规划方向

ROADMAP // 规划中，不构成承诺
  • 接入 Qomo 5.0 推理底座。
  • 任务自动拆解与多步工具调用。
  • 执行记录、结果沉淀与工作流复用。
  • 可插拔工具与扩展机制。
