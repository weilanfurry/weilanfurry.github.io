产品概述

OVERVIEW // AI 策略游戏

KiometAgent 是基于 Kiomet 改版的 AI 策略游戏： 由 AI 控制不同国家，在持续推进的战争与外交环境中 自主开展战争、合作与地盘扩张。

核心玩法

  • 国家由 AI 控制，玩家主要观察 AI 之间的博弈。
  • 战争、结盟谈判与领土变化由 AI 自主决策。
  • 版图会随着战争与合作持续改写，形成动态世界。

玩法方向

GAMEPLAY // 规划中，不构成承诺
  • 战争：AI 国家判断军力与形势，主动进攻、防御或停火。
  • 合作：AI 国家可以结盟、谈判，并根据局势决定是否背弃或维持。
  • 地盘扩张：领土争夺与版图变化可视化呈现。
  • 观战与干预：玩家观察全局演变，并在后续版本中提供可选干预入口。

当前状态

STATUS // 开发阶段
  • 处于玩法构思与原型设计阶段。
  • 尚未正式上线，仓库暂未公开。
  • 正式发布后将在 GitHub 组织下开放源码与文档。

规划方向

ROADMAP // 规划中，不构成承诺
  • 梳理 Kiomet 规则并抽象为可复现的游戏循环。
  • 设计 AI 国家决策模型（战争 / 合作 / 扩张）。
  • 实现地图与地盘变化可视化。
  • 开放试玩、数据回放与社区反馈入口。
