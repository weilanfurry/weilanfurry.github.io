Contribute // 如何参与

STEP.02

STEP.03

贡献须知 / CONTRIBUTION NOTES

  • 提交前先阅读对应仓库 README 与 LICENSE，确认许可与运行方式；已公开的仓库（如 tranxet-compat）可直接 Fork 提交 PR，规划中的产品暂不接受源码 PR。
  • Issue 描述请包含：环境、复现步骤、期望行为与实际行为。
  • PR 建议小步提交，并附带简要变更说明（CHANGELOG 条目更佳）。
  • 产品正式开源后，仓库地址将在官网「产品」与「仓库」页同步更新。
